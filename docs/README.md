# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
## Quick check

From the repository root, run Python to check the functions:

```python
from circle import area
from square import perimeter
assert round(area(1), 5) == 3.14159
assert perimeter(3) == 12
```
